مشروع استبيان الحصن + Discord Webhook
1) أنشئ Webhook جديدًا بعد إلغاء القديم المكشوف.
2) انسخ رابط Webhook وضعه في متغير البيئة DISCORD_WEBHOOK_URL.
3) ثبّت Node.js ثم نفّذ: npm install
4) شغّل: npm start
5) ضع background.jpg داخل public.
مهم: لا تضع رابط Webhook داخل index.html لأنه سر ويمكن لأي شخص رؤيته.
